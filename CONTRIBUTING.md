## Contribution Guidelines

We welcome contributions that help improve this project.

1. Discuss major changes with the team before implementation.
2. Create a separate branch for new features or bug fixes.
3. Write clear, maintainable, and well-structured code.
4. Test your changes before submitting them.
5. Use clear commit messages describing your changes.
6. Submit a pull request for review before merging changes into the main branch.

## Reporting Issues

If you find a bug or have a suggestion, open an issue in the GitHub repository and provide a clear description of the problem or proposed improvement.
